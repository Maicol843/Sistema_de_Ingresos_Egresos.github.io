# 📊 Sistema de Gestión de Ingresos y Egresos
### 🏢 Ministerio de Educación de la Provincia de Jujuy

¡Bienvenido al repositorio del **Sistema de Ingresos y Egresos**, una solución web institucional desarrollada para la digitalización, control y transparencia del flujo financiero de las distintas sedes del **Ministerio de Educación de Jujuy**.

🔗 **Demo:** [Visitar la aplicación en GitHub Pages](https://maicol843.github.io/Sistema_de_Ingresos_Egresos.github.io/)

---

## 📝 Descripción del Proyecto

Este sistema fue diseñado como una herramienta informática ágil y moderna para centralizar el registro de movimientos contables (entradas y salidas de fondos) de las dependencias educativas públicas. Al ser una aplicación basada puramente en tecnologías web del lado del cliente, ofrece una velocidad de respuesta inmediata, no requiere de servidores complejos para su ejecución y está lista para ser usada desde cualquier navegador.

---

## 🚀 Características Principales

* **🔒 Acceso Institucional Personalizado:** Pantalla de Login adaptada con la identidad del Ministerio, que permite seleccionar dinámicamente la sede correspondiente (Sede Central, Puesto de Marqués, Intermedia, Colonia San José, El Perchel, Tumbaya Grande, Tumbaya Pueblo, León, Termas de Reyes, Sunchal, Carahunco, San Juancito, Manantiales, entre otras).
* **📥 Control de Ingresos:** Formulario y tablas dinámicas para el registro riguroso de partidas presupuestarias, subsidios o asignaciones recibidas.
* **📤 Gestión de Egresos:** Módulo dedicado a la carga y categorización de gastos operativos, insumos, mantenimiento y servicios liquidados.
* **📤 Libros Contables:** Tablas de registros contrables como libro diario, libro de sumas y saldos, prebalance.
* **📈 Panel de Balance General:** Vista centralizada donde se procesan y muestran de forma automática los estados de cuenta, calculando en tiempo real el saldo remanente.
* **📊 Gráficas:** Gráficas Anuales y Mensuales de los registros contables.
* **📱 Diseño Responsivo e Institucional:** Interfaz limpia que implementa la paleta de colores y logotipos oficiales del Gobierno de Jujuy, optimizada para visualizarse correctamente tanto en computadoras de escritorio como en tablets o celulares.

---

## 🛠️ Tecnologías Utilizadas

El proyecto está desarrollado en su totalidad utilizando tecnologías nativas de la web (**Frontend Estático**):

* **HTML5:** Para la maquetación estructurada y semántica de los formularios, tablas de balances y secciones de navegación.
* **CSS3 & Bootstrap v5.3.2:** Para el diseño visual, tipografías corporativas (*Oswald* y *Roboto* de Google Fonts) y la adaptabilidad a pantallas de todo tamaño (Responsive Design).
* **Chart.js:** es una biblioteca de JavaScript de código abierto para crear los gráficos interactivos y dinámicos utilizando la etiqueta <canvas> de HTML5. 
* **Font Awesome v6.5.1:** Biblioteca de iconos vectoriales utilizada para mejorar la iconografía de los botones y paneles del sistema.
* **JavaScript (ES6+):** El motor principal del sistema. Se encarga de la interactividad, la validación del login, la inserción dinámica de datos en las tablas, el filtrado de registros y la realización automatizada de los cálculos matemáticos de sumas de ingresos, egresos y balances.

## 📂 Estructura del Proyecto

El código fuente está organizado de manera limpia y modular bajo la siguiente estructura de carpetas:

```bash
├── 📁 assets/          # Logotipos institucionales, recursos gráficos y fondos oficiales
├── 📁 css/             # Hojas de estilo del sistema (estilo-login.css, estilo-balanceGeneral.css, etc.)
├── 📁 html/            # Vistas secundarias de la aplicación (inicio.html, balanceGeneral.html, etc.)
├── 📁 js/              # Lógica de programación del sistema (login.js, balanceGeneral.js, etc.)
├── 📄 index.html       # Portal de acceso principal del Ministerio (Pantalla de Login)
└── 📄 README.md        # Documentación del proyecto (este archivo)
```
